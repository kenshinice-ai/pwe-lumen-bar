INSTALL
  Drag PWE Lumen Bar onto the Applications folder beside it, then
  open it from your Applications folder.

  If macOS refuses to open it the first time, right-click the app,
  choose Open, then click Open again. One-off.

IT LIVES IN THE MENU BAR
  There is no Dock icon. After launching, look for the display icon
  in the menu bar at the top right of your screen, near the clock.

    Click it            the panel — one card per display
    Scroll on it        brightness of whichever display the pointer
                        is on, without opening anything
    Right-click it      jump straight to a saved preset

APPLE SILICON ONLY
  Requires an M-series Mac on macOS 26 or later. On an Intel Mac the
  DDC/CI interface this app drives does not exist, and it will say so
  once and then stay out of your way.

TWO PERMISSIONS, BOTH OPTIONAL
  Accessibility      only if you want F1/F2 to control an external
                     display instead of the built-in one
  Screen Recording   only if you use per-display screenshots

  Everything else works without granting anything.

FREE AND OPEN SOURCE
  Every feature is free, with no trial and no key. The source is at
  github.com/kenshinice-ai/pwe-lumen-bar under the MIT licence
  (LICENSE.txt in this window). If it earns a place on your desk,
  pwestudio.site/support says how to give something back.

TWO THINGS NO SOFTWARE CAN UNDO
  Both ask first. Read this before you confirm either.

  Cut monitor power  Some monitors, told over DDC to power down,
                     leave the system entirely. Only the monitor's
                     own power button brings them back.
  Switch input       Sending the monitor to another input takes this
                     Mac's picture with it. Only the monitor's own
                     buttons bring it back.

  "Turn off" does neither: it takes the display off the desktop, and
  "Turn on" puts it back.

WHAT IT WRITES
  Display settings, on your Mac only. Nothing is uploaded and there
  is no account. Forced HiDPI is the one feature that writes a file
  to /Library, which macOS asks for your password to allow — the app
  never sees that password. Update checks are off until you turn
  them on.

  A log both the app and the command line write to is at
  ~/Library/Logs/PWE Lumen Bar/pwelumenbar.log

安装
  把 PWE Lumen Bar 拖到旁边的「应用程序」文件夹，然后从「应用程序」
  里打开它。

  如果第一次打开时 macOS 拒绝，右键点击应用，选「打开」，再点一次
  「打开」。只需要这一次。

它住在菜单栏里
  没有 Dock 图标。启动后，请在屏幕右上角、时钟附近找那个显示器图标。

    点击        打开面板 —— 一块屏一张卡片
    滚轮        直接调节光标所在那块屏的亮度，不用打开面板
    右键        直接切换已保存的场景

仅支持 Apple Silicon
  需要 M 系列芯片、macOS 26 或更新的系统。Intel 机器上没有本应用依赖
  的 DDC/CI 接口，它会说明一次，之后不再打扰。

两个权限，都可以不给
  辅助功能      只有当你想让 F1/F2 控制外接屏而不是内建屏时才需要
  屏幕录制      只有当你要用「按屏截图」时才需要

  其余功能不需要任何授权。

免费，开源
  所有功能免费，没有试用期，也不需要密钥。源代码在
  github.com/kenshinice-ai/pwe-lumen-bar，采用 MIT 协议（见本窗口里的
  LICENSE.txt）。如果它在你桌上派上了用场，pwestudio.site/support
  说了怎么支持我们。

两个软件无法撤销的操作
  两者都会先确认。确认前请先读这一段。

  给显示器断电    有些显示器收到 DDC 断电指令后会从系统里消失，
                  只能按显示器自己的电源键恢复。
  切换输入源      把显示器切到别的输入，这台 Mac 的画面也跟着走了，
                  只能用显示器自己的按键切回来。

  「熄屏」不属于这两种：它把屏移出桌面，「点亮」就能放回来。

它会写什么
  只写这台 Mac 上的显示设置。不上传，没有账号。只有「强制 HiDPI」
  会往 /Library 写一个文件，由 macOS 自己弹窗要管理员密码 —— 应用不
  接触这个密码。检查更新默认关闭，你打开了才会联网。

  应用和命令行共用的日志在
  ~/Library/Logs/PWE Lumen Bar/pwelumenbar.log
