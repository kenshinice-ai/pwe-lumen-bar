1. WHAT THIS SOFTWARE DOES
────────────────────────────────────────────────────────────────────
PWE Lumen Bar controls displays attached to an Apple Silicon Mac:
brightness, contrast, colour temperature, volume, resolution,
orientation, input source and power.

Some of that reaches the monitor over DDC/CI, which is a standard
every manufacturer implements differently. What a given monitor
supports is probed at run time and anything unavailable is shown as
unavailable rather than silently doing nothing.


2. TWO OPERATIONS YOU CANNOT UNDO FROM SOFTWARE
────────────────────────────────────────────────────────────────────
Both ask for confirmation first, and both are worth understanding
before you confirm:

  DDC power off      Some monitors, told to power down over DDC,
                     leave the system entirely. No software can wake
                     them. The physical power button is the only way
                     back.

  Input switching    Sending the monitor to another input takes this
                     Mac's picture away with it. Getting back means
                     the monitor's own buttons.

"Turn off" in the menu does neither of these — it disconnects the
display in software and is always reversible.


3. FORCED HiDPI
────────────────────────────────────────────────────────────────────
The Pro feature writes a display override file into /Library and
needs a restart to take effect. macOS asks for an administrator
password to allow the write; the application never handles it.

The override can be removed from the same menu it was installed
from. It affects only how macOS renders to that display.

1. 这个软件做什么

PWE Lumen Bar 控制接在 Apple Silicon Mac 上的显示器：亮度、对比度、

其中一部分通过 DDC/CI 抵达显示器，而这个标准每家厂商的实现都不同。
某台显示器到底支持什么，是运行时探测出来的；探不到的功能会在界面上

2. 两个软件无法撤销的操作
────────────────────────────────────────────────────────────────────
两者都会先弹窗确认，也都值得在确认前先弄清楚：

  DDC 断电        有些显示器收到 DDC 断电指令后会整个从系统里消失，
                  没有任何软件途径能唤醒它，只能按显示器的物理电源键。

  切换输入源      把显示器切到别的输入，就等于把这台 Mac 的画面一起
                  带走了。回来只能靠显示器自己的按键。

菜单里的「熄屏」不属于这两种：它走软件断开，永远可逆。

覆盖可以从安装它的同一个菜单里移除。它只影响 macOS 如何向那块屏渲染。
